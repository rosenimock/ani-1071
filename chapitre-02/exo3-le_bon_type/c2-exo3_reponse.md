# type de base le plus adaptés pour chacune des valeurs suivante 

   * UN AGE  
    - type :unsigned char ou entier non signé
    - taille et plage : 8 bits soit de 0 à 255 de plage            
    - operation refusée : une concaténation directe avec une chaine de caractères sans convertion

 * LE NOMBRE D'HABITANTS DE LA TERRE
    - type : long long ou entier long
    - taille et plage : 64 bits soit 9 milliards 
    - opération : une division par un caractère

* UNE TEMPERATURE EN DEGRES
    - type : float ou entier réel
    - taille et plage : 32 bits 
    - opération : des opération bits a bits ou opération de modulo

* LE CARACTERE TAPE AU CLAVIER
    - type : chzr ou caractère
    - taille et plage : 32 bits permet de stocker environ 256 symboles différents 
    - opération : une multiplication arithmétique directe entre deux caractères

* LE FAIT QU'UNE PORTE SOIT OUVERTE
    - type : bool ou entier booléen
    - taille et plage : 8 bits et prends uniquement les valeurs vrai ou faux
    - opération : une addition arithmétique pour obtenir une grandeur physique ou une racine carrée

* LE NOMBRE DE PIXELS D'UNE IMAGE DE 4000*3000
    - type : int ou entier 
    - taille et plage : 32 bits soit 2,1 milliards 
    - opération : une opération de découpage de chaine de caractères 

* UN SOLDE BANCAIRE EN FRANCS CFA
    - type : long long ou entier long
    - taille et plage : 64 bits soit 9 milliards 
    - opération : une opération logique ou de manipulation de bits qui n'ont aucun sens dans le contexte financier
